# 도형탐구실 · 다면체

중학교 1학년 다면체 관찰, 정다면체 발견 실험, 학생 탐구 노트 제출과 교사 수합.

- `/`: 교사·학생 역할 선택.
- `/student.html`: 수업 코드·번호·이름 입력 후 입장.
- `/explore.html`: 기존 관찰실·접기 실험·탐구 노트. 첫 두 탐구 화면과 도형 데이터는 최초 버전과 동일.
- `/teacher.html`: 교사 수합함. 수업 생성, 제출 코드 배포, 마감·재개, 학생별 답변, 전체 이력 CSV.
- `/api/notebooks/*`: 수업·제출 API. 학생은 코드로 제출하고 교사는 교사번호로 확인된 로그인 세션으로 조회.
- `TEACHER_PIN`: 교사 로그인에 사용할 6자리 번호. Sites 런타임 비밀 설정으로 구성하고 소스에 넣지 않음.
- D1 `DB`: 교사 소유 수업과 변경되지 않는 제출 이력, 해시로 저장한 로그인 세션과 로그인 시도 횟수. 적용된 마이그레이션은 변경하지 않고 이후 변경은 새 파일로 추가.

학생 작성 중 답변은 기존과 같이 현재 브라우저에 저장되고, 명시적으로 제출한 내용은 D1에 저장됩니다. 제출 중 통신이 실패해도 같은 요청 번호로 재시도하여 중복을 피합니다. 변경한 답변을 다시 제출하면 새 이력으로 보관합니다.

교사 권한과 수업 소유권은 API에서 검증합니다. 기존 수업의 교사 ID를 유지하여 교사번호로 로그인해도 이전 수업과 제출물을 계속 확인합니다. 학생 식별 정보는 자가 입력이며 출석 번호 기준으로 집계하므로 이름과 함께 확인해야 합니다. 사이트 첫 화면과 학생 입장은 계정 없이 접근하며 교사 기능은 서버에서 교사번호 세션을 검사합니다.

## 검증

- `node tests/notebooks.test.mjs`: 실제 SQLite에 생성 마이그레이션을 적용하여 권한·수업 소유권·제출 검증·재시도·재제출·마감·페이지 분할 검사.
- `node_modules/.bin/tsc --noEmit`
- Sites `build-site.mjs`로 빌드.

수업별로 탐구 노트 제출 여부 및 추가 질문(최대 5개)을 설정할 수 있습니다. 학생 입장 시 수업 설정을 불러오며 제출 시 서버가 필수 항목을 다시 검증합니다. 추가 질문은 제출 당시 문구와 답변을 함께 저장합니다. 학생별 브라우저 초안을 분리하고 번호·이름 변경 후 해당 학생 초안으로 전환합니다.

교사번호는 런타임 비밀 설정에서만 읽고 브라우저로 전달하지 않습니다. 로그인 성공 시 12시간 동안 유효한 Secure·HttpOnly·SameSite 쿠키를 발급합니다. 로그아웃은 서버 세션을 폐기합니다. IP별 고정 시간 창에서 로그인 시도 횟수를 제한합니다. 세션 토큰은 무작위로 생성하고 DB에는 해시만 저장합니다.
